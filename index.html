内容目录

        

        
文章将读写到 {内容目录}/{slug}.md。登录使用 Personal Access Token，无需 Serverless Functions，纯前端直接调用 GitHub API。

      


      

        

          
          
        

        
在 GitHub 生成 Personal Access Token（勾选 repo 权限）后粘贴到上方。Token 仅保存在本浏览器 localStorage。还没有令牌？前往 github.com/settings/tokens 获取。

      


      

        
        

          
          
        

        
由后端服务代理 GitHub（OAuth 登录，无需自建 Token）。填写后端地址后点登录会跳转到后端完成 GitHub 授权；留空则使用上方的 Personal Access Token 直连模式。
